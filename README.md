# dotfiles

## Sources

Under this section, some references are given to people and websites that have influenced and/or continue to influence these dotfiles.

### Useful Resources

This is a list of useful resources on Nix, NixOS and Home Manager that I consult from time to time:

- [Nix Reference Manual](https://nix.dev/manual/nix/2.25/introduction) for general information about Nix
- [Noogλe](https://noogle.dev/) for Nix functions
- [NixOS Search - Packages](https://search.nixos.org/packages) for Nix packages
- [NixOS Wiki](https://wiki.nixos.org/wiki/NixOS_Wiki) for NixOS configuration and explanations
- [MyNixOS](https://mynixos.com/) for NixOS options
- [Home Manager - Option Search](https://home-manager-options.extranix.com/) for Home Manager options
- [Nixpkgs Tracker](https://nixpkgs-tracker.ocfox.me/) to see where certain features or fixes are available
